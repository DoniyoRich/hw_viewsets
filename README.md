## Описание

1. Создан Django-проект, подключен DRF в настройках.
2. Созданы следующие модели:

### Пользователь:

- все поля от обычного пользователя, но авторизацию заменена на email;
- телефон;
- город;
- аватарка.

### Курс:

- название;
- превью (картинка);
- описание.

### Урок:

- название,
- описание,
- превью (картинка),
- ссылка на видео.
  Урок и курс - это связанные между собой сущности.
  Уроки складываются в курс, в одном курсе может быть много уроков. Реализована связь "один-ко-многим".

3. Описаны CRUD операции для моделей курса и урока.

Для работы контроллеров описаны простейшие сериализаторы.
При реализации CRUD для курсов и уроков реализованы все необходимые операции
(получение списка, получение одной сущности, создание, изменение и удаление).
Для курсов использованы Viewsets, а для уроков - Generic-классы.

Для начального заполнения БД и тестирования данных подготовлена фикстура ***lms_fixture.json*** (в корневой папке проекта).
